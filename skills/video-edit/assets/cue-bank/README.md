# Editorial Cue Bank

These 33 Original Synthesized Sounds Were Designed For Social Cut Kit. Use Short Taps To Mark Interface Actions, Sweeps To Bridge Shots, And Low Impacts To Land A Reveal. The Three Longer Beds Are Quiet Textures For Gaps Between Cuts. Crossfade Repetitions And Audition The Mix Under Speech.

Add A WAV As An Audio Asset In The Timeline And Set Its Start, End, And Gain. Listen Both On Headphones And At Phone Speaker Level. Source Audio Stays On Its Own Track.

The `sounds/` Folder Contains The Actual PCM WAVs And A SHA-256 Index. To Rebuild The Collection In A New Directory, Run `python build.py fresh-cues`.
